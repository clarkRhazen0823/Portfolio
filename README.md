## 👨‍💻 About Me

I am an IT student at West Visayas State University, bridging the gap between creative interface design and front-end development. This repository contains the source code for my personal portfolio website, which is designed to showcase my technical skills, educational background, and recent projects.

## ✨ Features

* **Fully Responsive Layout:** Optimized for mobile, tablet, and desktop viewing using modern CSS media queries.
* **Interactive Lightbox Gallery:** A custom-built media gallery modal supporting both images and video walkthroughs, complete with keyboard navigation (arrows and escape keys).
* **Functional Contact Form:** Seamlessly integrated with EmailJS to allow visitors to send direct inquiries to my email without needing a backend database. Includes loading, success, and error button states.
* **Modern UI/UX:** Implements CSS variables, glassmorphism (backdrop blur) effects, smooth scrolling, and hover animations for an engaging human-centered digital experience.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **APIs & Libraries:** EmailJS (Client-side email handling), FontAwesome 7.0 (Iconography)
* 
**Design & IDE Tools:** Visual Studio Code, Git/GitHub, Canva

## ⚙️ Local Setup

1. Clone the repository:
```bash
git clone https://github.com/clarkRhazen0823/Portfolio.git

```


2. Open `index.html` in your preferred web browser.
3. **Note on Contact Form:** To make the contact form work for your own environment, replace the EmailJS `publicKey`, `Service ID`, and `Template ID` inside `script/email.js` with your personal EmailJS account credentials.
